# محرك المحتوى اليومي — @Teacher_Meshal

يُعِدّ منشورًا أو منشورين يوميًا بحسب الخطة: نص X، ونص تيليجرام، وإنفوجرافيك بالهوية وخط ثمانية. ثم يرسلها إلى سيدي في بوت تيليجرام خاص لاعتمادها. يعمل على رصيد Claude API وحده، فلا يمسّ حدود الاشتراك.

## كيف يعمل
1. **GitHub Actions** يعمل يوميًا الساعة 5:30 صباحًا و6:30 مساءً بتوقيت الرياض، فيولّد المنشور إن كان مجدولًا في `knowledge/plan.json`.
2. **الكاتب** (Claude API) يكتب مرشّحين بزاويتين مختلفتين.
3. **لجنة المراجعة** تعمل في استدعاء واحد بثلاث عيون: الدقة والمنهج، والهوية والخطوط الحمراء، والإبداع. تختار المرشّح الأقوى وتصقله وتعطيه درجة.
4. **الرسم:** `engine/render.py` يرسم الإنفوجرافيك (1080×1350 بدقة مضاعفة) بستة قوالب: concept، وcompare، وsteps، وmistake، وscratch (لبنات سكراتش حقيقية الشكل)، وstatement. فإن فاض النص عن البطاقة اختصره الكاتب آليًا.
5. **البوت** يرسل إلى سيدي رسالتين:
   - الصورة وعليها نص تيليجرام.
   - نص X في كتلة تُنسخ بلمسة، ومعه ملاحظات المراجعين وزرّان:
     - **✅ انشر:** ينسخ الصورة ونصها إلى القناة عبر `worker/`.
     - **🔁 بديل جديد:** يطلب منشورًا آخر.
6. اكتب للبوت «عدّل: …» أو «منشور: …» ليُعَدّ منشور جديد بتوجيهك.
7. **السجل:** `history/posts.jsonl` يمنع تكرار المواضيع، ويدير تناوب الصفوف والمناسبات.

## الملفات
| الملف | ما فيه |
|---|---|
| `knowledge/plan.json` (في السر KNOWLEDGE) | الهدف، والإيقاع الأسبوعي، والأركان، والتقويم، والمناسبات |
| `knowledge/voice.md` (في السر KNOWLEDGE) | صوت الحساب وقواعده وخطوطه الحمراء |
| `knowledge/terms.md` | مصطلحات الواجهة ولبنات سكراتش كما في كتب 1448 |
| `knowledge/curriculum.json`، `term2-weeks.json` | فهارس الفصلين، وتوزيع أسابيع الفصل الثاني (من مستودع المنصة) |
| `knowledge/lab.json` (في السر KNOWLEDGE) | حقائق المعمل المسموح ذكرها وما لا يُذكر |
| `templates/card.html` | قالب الإنفوجرافيك |
| `worker/` | بوت الأزرار على Cloudflare Workers (الخطة المجانية) |

## الخصوصية
المستودع عام ليعمل Actions مجانًا، أما الخطة والصوت وحقائق المعمل فمحفوظة في السر `KNOWLEDGE` (أرشيف tar.gz بترميز base64) وتُفك عند كل تشغيل. لتحديثها: `tar czf - -C knowledge voice.md plan.json lab.json | base64 -w0` ثم يُستبدل السر.

## الإعداد (مرة واحدة)
1. **المستودع:** مستودع خاص على GitHub، ويُرفع إليه هذا المجلد.
2. **أسرار المستودع** (Settings ← Secrets and variables ← Actions):
   - `ANTHROPIC_API_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `OWNER_CHAT_ID`
3. **البوت:**
   - يُنشأ من BotFather.
   - يُضاف مشرفًا في قناة @Teacher_Meshal بصلاحية النشر.
4. **الـWorker:** يُنشر بالأسرار التالية:
   - `TELEGRAM_BOT_TOKEN`، و`OWNER_CHAT_ID`.
   - `CHANNEL_ID` (مثل `@Teacher_Meshal`).
   - `WEBHOOK_SECRET`: نص عشوائي.
   - `GH_TOKEN`: رمز دقيق الصلاحية لهذا المستودع وحده، بصلاحية Actions: write.
   - `GH_REPO`.
5. **ربط الـWebhook:** يُستدعى `setWebhook` برابط الـWorker مع `secret_token`.
6. **تجربة أولى:** من Actions ← engine ← Run workflow.

## الكلفة
- GitHub Actions: مجاني.
- Cloudflare Worker: مجاني.
- Claude API: من رصيد Console. يطبع كل تشغيل استهلاكه في السجل `[usage]`.
- النموذج قابل للتغيير بمتغير المستودع `MODEL`، والافتراضي claude-opus-5-5.
